# Lab 03 - Managing Files

## Overview

This lab demonstrates fundamental file management operations such as creating, copying, moving, renaming, and deleting files.

## Commands Practiced

```bash
touch file1.txt
cp file1.txt backup.txt
mv file1.txt newfile.txt
rm newfile.txt
ls
```

## Key Concepts

- File Creation
- File Copying
- File Renaming
- File Deletion

## Practical Outcome

Successfully managed files using essential Linux file handling commands.
