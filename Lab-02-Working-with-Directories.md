# Lab 02 - Working with Directories

## Overview

This lab focuses on creating, managing, renaming, and removing directories in Linux using basic command-line utilities.

## Commands Practiced

```bash
mkdir testdir
ls
rmdir testdir
mkdir projects
mv projects linux-projects
```

## Key Concepts

- Directory Creation
- Directory Removal
- Directory Renaming
- Filesystem Organization

## Practical Outcome

Successfully created, renamed, and removed directories while understanding Linux directory structures.
