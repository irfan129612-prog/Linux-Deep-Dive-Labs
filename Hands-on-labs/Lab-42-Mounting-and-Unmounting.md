# Lab 42 - Mounting and Unmounting

## Overview

This lab demonstrates how to mount and unmount filesystems in Linux.

## Commands Practiced

```bash
sudo mkdir /mnt/my_mount
lsblk
sudo mount /dev/sdb1 /mnt/my_mount
sudo umount /mnt/my_mount
```

## Key Concepts

- Mount Points
- Filesystems
- Storage Access
- Device Management

## Practical Outcome

Successfully mounted and unmounted storage devices in Linux.
