# Lab 24 - Disk Usage and File Size

## Overview

This lab demonstrates how to analyze disk usage and identify large files and directories.

## Commands Practiced

```bash
du -sh /home/user/Documents
du -ah /home/user/Documents | sort -rh | head
```

## Key Concepts

- Disk Usage Analysis
- Storage Monitoring
- File Size Inspection

## Practical Outcome

Successfully analyzed storage consumption across directories.
