# Lab 22 - Package Management (YUM/DNF)

## Overview

This lab focuses on package management using YUM and DNF on Red Hat-based distributions.

## Commands Practiced

```bash
sudo dnf update
sudo dnf install package_name
sudo dnf remove package_name
dnf search keyword
```

## Key Concepts

- RPM Packages
- Software Installation
- Package Repositories

## Practical Outcome

Successfully managed software packages using YUM/DNF.
