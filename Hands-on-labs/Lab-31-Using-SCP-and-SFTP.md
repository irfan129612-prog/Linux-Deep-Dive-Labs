# Lab 31 - Using SCP and SFTP

## Overview

This lab demonstrates secure file transfers between Linux systems using SCP and SFTP.

## Commands Practiced

```bash
scp file.txt user@remote:/home/user/
scp user@remote:/home/user/file.txt .

sftp user@remote
put file.txt
get file.txt
exit
```

## Key Concepts

- Secure Copy Protocol (SCP)
- Secure File Transfer Protocol (SFTP)
- SSH-Based Transfers
- Secure Data Exchange

## Practical Outcome

Successfully transferred files securely between local and remote systems.
