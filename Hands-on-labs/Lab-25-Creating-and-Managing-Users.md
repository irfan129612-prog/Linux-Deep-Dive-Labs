# Lab 25 - Creating and Managing Users

## Overview

This lab introduces user account management and demonstrates how to create, modify, and remove users.

## Commands Practiced

```bash
sudo useradd testuser
sudo passwd testuser
sudo usermod testuser
sudo userdel testuser
```

## Key Concepts

- User Administration
- Password Management
- Account Lifecycle

## Practical Outcome

Successfully created, modified, and removed Linux user accounts.
