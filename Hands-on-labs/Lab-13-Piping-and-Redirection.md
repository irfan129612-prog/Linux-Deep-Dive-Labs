# Lab 13 - Piping and Redirection

## Overview

This lab explores command chaining through pipes and output redirection for efficient data processing.

## Commands Practiced

```bash
ls > files.txt
cat files.txt
cat log.txt | grep error
echo "Hello" >> file.txt
```

## Key Concepts

- Standard Input
- Standard Output
- Pipes
- Output Redirection

## Practical Outcome

Successfully redirected command output and chained commands using pipes.
