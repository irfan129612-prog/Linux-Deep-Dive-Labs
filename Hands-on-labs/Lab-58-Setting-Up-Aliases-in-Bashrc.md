# Lab 58 - Setting Up Aliases in Bashrc

## Overview

This lab demonstrates creating permanent aliases using the .bashrc configuration file.

## Commands Practiced

```bash
cd ~
ls -a
nano .bashrc

alias update='sudo apt-get update && sudo apt-get upgrade'

source ~/.bashrc

update
```

## Key Concepts

- Bash Customization
- Aliases
- Productivity
- Shell Configuration

## Practical Outcome

Successfully created persistent aliases in the Linux shell.
