# Lab 07-using-Wildcards

## Overview

This lab explores wildcard characters for performing operations on multiple files efficiently.

## Commands Practiced

```bash
touch file1.txt file2.txt file3.txt
ls *.txt
cp *.txt backup/
rm *.txt
```

## Key Concepts

- Wildcard Matching
- Pattern Expansion
- Batch Operations
- File Selection

## Practical Outcome

Successfully used wildcard characters to simplify file management tasks.
