# Lab 29 - Scheduling Tasks with at

## Overview

This lab introduces one-time task scheduling using the at utility.

## Commands Practiced

```bash
at now + 5 minutes
atq
atrm 1
```

## Example Task

```bash
echo "System Maintenance" | at 10:00 PM
```

## Key Concepts

- One-Time Scheduling
- Task Queue
- Deferred Execution

## Practical Outcome

Successfully scheduled and managed one-time administrative tasks.
