# Lab 09 - Working with Links

## Overview

This lab introduces hard links and symbolic links and explains their usage in Linux filesystems.

## Commands Practiced

```bash
ln file.txt hardlink
ln -s file.txt symlink
ls -li
```

## Key Concepts

- Hard Links
- Symbolic Links
- Inodes
- File References

## Practical Outcome

Successfully created and managed hard and symbolic links in Linux.
