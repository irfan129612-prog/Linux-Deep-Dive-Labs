# Lab 12 - Basic Shell Scripting

## Overview

This lab introduces Bash scripting fundamentals and demonstrates how to create and execute simple shell scripts.

## Commands Practiced

```bash
nano script.sh
chmod +x script.sh
./script.sh
```

## Key Concepts

- Bash Scripting
- Script Execution
- Automation
- Shell Programming

## Practical Outcome

Successfully created and executed a shell script to automate repetitive tasks.
