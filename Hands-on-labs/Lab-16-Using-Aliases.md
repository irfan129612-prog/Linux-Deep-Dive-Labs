# Lab 16 - Using Aliases

## Overview

This lab demonstrates how to create command aliases to improve efficiency and simplify repetitive commands.

## Commands Practiced

```bash
alias ll='ls -la'
alias update='sudo apt update'
unalias ll
```

## Key Concepts

- Command Aliases
- Shell Customization
- Productivity Enhancement

## Practical Outcome

Successfully created and managed aliases for frequently used commands.
