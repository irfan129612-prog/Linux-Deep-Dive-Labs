# Lab 33 - Basic Grep Usage

## Overview

This lab demonstrates how to search text efficiently using grep.

## Commands Practiced

```bash
grep "error" file.txt
grep -r "password" /etc/
grep -A 2 -B 2 "timeout" config.txt
```

## Key Concepts

- Pattern Matching
- Recursive Search
- Log Analysis
- Text Filtering

## Practical Outcome

Successfully searched files and directories using grep.
