# Lab 19 - Compressing with Gzip and Bzip2

## Overview

This lab focuses on file compression and decompression using gzip and bzip2 utilities.

## Commands Practiced

```bash
gzip file.txt
gunzip file.txt.gz
bzip2 file.txt
bunzip2 file.txt.bz2
```

## Key Concepts

- File Compression
- Storage Optimization
- Data Archiving

## Practical Outcome

Successfully compressed and decompressed files using Linux compression tools.
