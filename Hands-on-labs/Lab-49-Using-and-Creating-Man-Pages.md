# Lab 49 - Using and Creating Man Pages

## Overview

This lab demonstrates how to use existing man pages and create custom documentation.

## Commands Practiced

```bash
man ls
nano test_script.sh
nano test_script.1
gzip test_script.1
sudo mv test_script.1.gz /usr/local/share/man/man1/
man test_script
```

## Key Concepts

- Documentation
- Manual Pages
- Linux Help System
- Script Documentation

## Practical Outcome

Successfully created and installed a custom Linux man page.
