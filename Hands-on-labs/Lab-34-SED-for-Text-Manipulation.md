# Lab 34 - sed for Text Manipulation

## Overview

This lab introduces the sed stream editor for text replacement and filtering.

## Commands Practiced

```bash
sed 's/World/Earth/g' example.txt
sed -i 's/World/Earth/g' example.txt
sed '/Universe/d' example.txt
sed -i '/Universe/d' example.txt
```

## Key Concepts

- Stream Editing
- Text Substitution
- Pattern Deletion
- File Manipulation

## Practical Outcome

Successfully modified and filtered text using sed.
