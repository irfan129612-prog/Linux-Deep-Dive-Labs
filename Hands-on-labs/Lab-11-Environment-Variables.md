# Lab 11 - Environment Variables

## Overview

This lab introduces environment variables in Linux and demonstrates how to create, export, view, and remove variables within a shell session.

## Commands Practiced

```bash
env
export MYVAR="Hello"
echo $MYVAR
unset MYVAR
```

## Key Concepts

- Environment Variables
- Shell Variables
- Export Command
- Session Configuration

## Practical Outcome

Successfully configured and managed environment variables in a Linux shell environment.
