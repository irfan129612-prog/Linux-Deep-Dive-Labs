# Lab 51 - Basic Regex with Grep

## Overview

This lab demonstrates basic regular expressions using grep for text filtering.

## Commands Practiced

```bash
grep '^a' example.txt
grep 'y$' example.txt
grep 'colou?r' colourExample.txt
```

## Key Concepts

- Regular Expressions
- Pattern Matching
- Text Filtering
- Search Automation

## Practical Outcome

Successfully searched text using regex patterns with grep.
