# Lab 39 - Basic Firewall Setup (UFW)

## Overview

This lab introduces firewall management using UFW on Ubuntu-based systems.

## Commands Practiced

```bash
sudo apt install ufw
sudo ufw enable
sudo ufw allow ssh
sudo ufw allow http
sudo ufw status
sudo ufw status verbose
```

## Key Concepts

- Firewall Security
- UFW Management
- Network Access Control
- System Hardening

## Practical Outcome

Successfully configured and managed firewall rules using UFW.
