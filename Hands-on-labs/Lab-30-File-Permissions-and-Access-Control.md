# Lab 30 - File Permissions and Access Control

## Overview

This lab reinforces Linux permission management and access control mechanisms.

## Commands Practiced

```bash
ls -l
chmod 644 file.txt
chmod 755 script.sh
chown user:user file.txt
```

## Key Concepts

- File Permissions
- Access Control
- Ownership Management
- Linux Security

## Practical Outcome

Successfully configured secure access permissions for files and directories.
