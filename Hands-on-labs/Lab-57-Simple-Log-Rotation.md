# Lab 57 - Simple Log Rotation

## Overview

This lab demonstrates how Linux log rotation works using logrotate.

## Commands Practiced

```bash
cat /etc/logrotate.conf
cd /etc/logrotate.d
ls
cat apache2
sudo logrotate --force /etc/logrotate.conf
ls -ltr /var/log
```
