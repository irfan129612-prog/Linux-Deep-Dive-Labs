# Lab 27 - Password Policies

## Overview

This lab focuses on password management and enforcing password policies for Linux user accounts.

## Commands Practiced

```bash
sudo passwd testuser
sudo chage -l testuser
sudo chage -M 90 testuser
sudo chage -W 7 testuser
```

## Key Concepts

- Password Aging
- Account Security
- Password Expiration
- Security Policies

## Practical Outcome

Successfully configured password expiration and account security settings.
