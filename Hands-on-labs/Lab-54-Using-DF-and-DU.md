# Lab 54 - Using df and du

## Overview

This lab demonstrates how to analyze disk usage and storage consumption.

## Commands Practiced

```bash
df -h

du -sh /home/user/Documents

du -ah /home/user/Documents | sort -rh | head -n 10
```

## Key Concepts

- Disk Usage
- Storage Monitoring
- Filesystem Analysis
- Capacity Planning

## Practical Outcome

Successfully analyzed storage usage across filesystems and directories.
