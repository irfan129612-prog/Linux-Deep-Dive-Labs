# Lab 52 - Network File Transfers (wget/curl)

## Overview

This lab demonstrates downloading files and web content using wget and curl.

## Commands Practiced

```bash
wget https://example.com/sample-file.txt
ls

curl https://example.com
curl https://example.com -o webpage.html

nano webpage.html

wget https://example.com/large-sample-file.zip
wget -c https://example.com/large-sample-file.zip
```

## Key Concepts

- File Downloads
- Web Requests
- Resume Downloads
- Data Retrieval

## Practical Outcome

Successfully downloaded files and web content using wget and curl.
