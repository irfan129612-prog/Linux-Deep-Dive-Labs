# Lab 60 - Introduction to SELinux

## Overview

This lab introduces SELinux and demonstrates how to check and modify SELinux modes.

## Commands Practiced

```bash
sestatus

sudo vi /etc/selinux/config

SELINUX=permissive
SELINUX=enforcing

sudo reboot

sestatus
```

## Key Concepts

- SELinux
- Mandatory Access Control
- Security Policies
- System Hardening

## Practical Outcome

Successfully explored SELinux configuration and security modes.
