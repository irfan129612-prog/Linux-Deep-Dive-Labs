# Lab 26 - Group Management Basics

## Overview

This lab introduces Linux group administration and demonstrates how to create, modify, and manage user groups.

## Commands Practiced

```bash
groups
sudo groupadd developers
sudo usermod -aG developers testuser
sudo groupdel developers
```

## Key Concepts

- Group Administration
- User Groups
- Access Management
- Permission Control

## Practical Outcome

Successfully created and managed Linux groups while assigning users to appropriate groups.
