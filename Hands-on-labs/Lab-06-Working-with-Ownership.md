# Lab 06 - Working with Ownership

## Overview

This lab demonstrates how file ownership works in Linux and how users and groups can be assigned to files.

## Commands Practiced

```bash
ls -l
chown user file.txt
chgrp developers file.txt
chown user:developers file.txt
```

## Key Concepts

- User Ownership
- Group Ownership
- Ownership Management
- Security Administration

## Practical Outcome

Successfully assigned and modified file ownership for users and groups.
