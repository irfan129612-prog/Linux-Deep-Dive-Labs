# Lab 50 - Introduction to Shell Variables

## Overview

This lab introduces shell variables and demonstrates local, global, and special variables.

## Commands Practiced

```bash
MYVAR="HelloWorld"
echo $MYVAR

export MYVAR2="GlobalHello"
bash -c 'echo $MYVAR2'

echo $?
echo $$
bash -c 'echo $#'
```

## Key Concepts

- Local Variables
- Global Variables
- Environment Variables
- Special Variables

## Practical Outcome

Successfully created and utilized shell variables within Linux.
