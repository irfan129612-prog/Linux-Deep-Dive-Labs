# Lab 36 - Searching with Find

## Overview

This lab demonstrates advanced file searching techniques using the find command.

## Commands Practiced

```bash
find ~ -name "*.txt"
find ~ -size +1M
find ~ -name "*.txt" -exec wc -l {} \;
```

## Key Concepts

- File Discovery
- Search Filters
- File Size Analysis
- Command Execution

## Practical Outcome

Successfully located and analyzed files using find.
