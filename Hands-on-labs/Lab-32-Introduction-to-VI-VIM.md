# Lab 32 - Introduction to VI/VIM

## Overview

This lab introduces the Vim text editor and demonstrates basic editing and navigation techniques.

## Commands Practiced

```bash
vi file.txt
i
:w
:q
:%s/old/new/g
```

## Key Concepts

- Vim Editor
- Insert Mode
- Command Mode
- Search and Replace

## Practical Outcome

Successfully edited files using the Vim text editor.
