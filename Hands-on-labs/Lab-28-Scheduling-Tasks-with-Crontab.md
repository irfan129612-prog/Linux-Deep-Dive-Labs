# Lab 28 - Scheduling Tasks with Crontab

## Overview

This lab demonstrates how to automate recurring tasks using the Linux cron scheduler.

## Commands Practiced

```bash
crontab -e
crontab -l
crontab -r
```

## Example Cron Job

```bash
0 2 * * * /home/user/backup.sh
```

## Key Concepts

- Task Automation
- Cron Jobs
- Scheduled Tasks
- System Administration

## Practical Outcome

Successfully created and managed scheduled tasks using cron.
