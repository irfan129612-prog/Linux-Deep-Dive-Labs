# Lab 41 - Basic Disk Partitioning

## Overview

This lab introduces disk partitioning concepts and demonstrates how to view, create, and remove partitions using Linux tools.

## Commands Practiced

```bash
lsblk
sudo fdisk -l /dev/sda
sudo cfdisk /dev/sda
```

## Key Concepts

- Disk Partitioning
- Block Devices
- Partition Tables
- Storage Management

## Practical Outcome

Successfully viewed, created, and removed disk partitions in a Linux environment.
