# Lab 35 - AWK for Data Processing

## Overview

This lab explores data extraction and filtering using the AWK utility.

## Commands Practiced

```bash
awk '{print $1, $3}' data.txt
awk '$2 > 25 {print $0}' data.txt
```

## Key Concepts

- Data Extraction
- Column Processing
- Conditional Filtering
- Text Analytics

## Practical Outcome

Successfully processed structured text data using AWK.
