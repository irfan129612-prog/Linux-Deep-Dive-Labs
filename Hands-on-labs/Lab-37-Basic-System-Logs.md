# Lab 37 - Basic System Logs

## Overview

This lab introduces Linux system logs and demonstrates log monitoring techniques.

## Commands Practiced

```bash
cd /var/log
ls -lh
less syslog
grep "error" syslog
tail -f syslog
```

## Key Concepts

- System Logging
- Log Analysis
- Real-Time Monitoring
- Troubleshooting

## Practical Outcome

Successfully monitored and analyzed Linux system logs.
