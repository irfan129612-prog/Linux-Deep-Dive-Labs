# Lab 45 - Introduction to /etc/fstab

## Overview

This lab explores the Linux fstab file and demonstrates automatic filesystem mounting.

## Commands Practiced

```bash
sudo nano /etc/fstab
lsblk
sudo cp /etc/fstab /etc/fstab.bak
sudo mkdir -p /media/usb
sudo mount -a
df -h
```

## Key Concepts

- Filesystem Table
- Automatic Mounting
- Persistent Storage Configuration
- Linux Boot Process

## Practical Outcome

Successfully configured persistent filesystem mounts using fstab.
