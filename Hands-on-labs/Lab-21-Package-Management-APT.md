# Lab 21 - Package Management (APT)

## Overview

This lab introduces package management using the APT package manager on Debian-based systems.

## Commands Practiced

```bash
sudo apt update
sudo apt install package_name
sudo apt remove package_name
apt search keyword
```

## Key Concepts

- Package Installation
- Package Removal
- Repository Management

## Practical Outcome

Successfully managed software packages using APT.
