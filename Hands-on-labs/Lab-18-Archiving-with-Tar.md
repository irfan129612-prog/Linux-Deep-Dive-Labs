# Lab 18 - Archiving with Tar

## Overview

This lab demonstrates how to create, view, and extract archive files using the tar utility.

## Commands Practiced

```bash
tar -czf backup.tar.gz folder/
tar -tzf backup.tar.gz
tar -xzf backup.tar.gz
```

## Key Concepts

- Archiving
- Compression
- Backup Management

## Practical Outcome

Successfully created and extracted compressed archive files.
