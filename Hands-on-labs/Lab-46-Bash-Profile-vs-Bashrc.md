# Lab 46 - Bash Profile vs Bashrc

## Overview

This lab explains the differences between .bash_profile and .bashrc while demonstrating shell customization.

## Commands Practiced

```bash
cd ~
ls -a
nano ~/.bash_profile
nano ~/.bashrc
cp ~/.bashrc ~/.bashrc.backup
cp ~/.bash_profile ~/.bash_profile.backup
source ~/.bashrc
echo $MY_VAR
```

## Key Concepts

- Login Shells
- Interactive Shells
- Environment Customization
- Aliases and Variables

## Practical Outcome

Successfully customized the shell environment using Bash configuration files.
